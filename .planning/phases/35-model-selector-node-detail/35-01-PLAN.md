  <action>
    In node_detail.html: Insert a new card section after the Node Info card closing tag (line 64) and before the recommendations-panel section (line 66). The card has:
    - section element with class "card" and id "setup-config-panel"
    - h2 with class "card-title" and text "Setup Configuration"
    - A div containing: a native select element with id "model-select" (styled inline with background var(--bg), color var(--fg), border 1px solid var(--border), padding 0.375rem 0.5rem, border-radius 4px, font-size 0.875rem, width 100%, max-width 400px) and a span with id "model-status" (styled with color var(--muted), font-size 0.875rem, display none initially). Per D-01 placement and D-07 native select.

    In node_detail.js: Add three things at module level, before the DOMContentLoaded handler (before line 629):

    1. A module-level variable: var catalogModels = [];

    2. A function getSelectedModel() that reads document.getElementById("model-select").value and returns it (or empty string if no selection). This is the helper that ACTION_CONFIG body functions call.

    3. An async function fetchCatalog() that:
       - Fetches GET /admin/models/catalog
       - On success, stores response.models array in catalogModels
       - Gets the select element (model-select) and the status span (model-status)
       - If catalogModels is empty (per D-05): hides the select (display none), shows model-status with text "No models downloaded" (display inline)
       - If catalogModels has entries (per D-06): shows the select, hides model-status, clears existing options, creates an option element for each model (value = repo_id, textContent = repo_id), appends to select. First model is pre-selected by default (natural select behavior).
       - On fetch error: treat same as empty catalog (show "No models downloaded")

    4. Modify ACTION_CONFIG.setup.body (line 19) from:
       body: function (id) { return { hostname: id }; }
       to:
       body: function (id) { var b = { hostname: id }; var m = getSelectedModel(); if (m) b.model = m; return b; }
       Per D-02 and D-03 — setup action reads selected model from the card.

    5. Modify ACTION_CONFIG.retry.body (line 32) with the same pattern:
       body: function (id) { var b = { hostname: id }; var m = getSelectedModel(); if (m) b.model = m; return b; }
       Per D-03 — retry also sends the selected model.

    6. In refreshDetail() (around line 181), where createActionsDropdown is called with node.actions: Before that call, if catalogModels.length === 0, filter "setup" out of the actions array so the setup button is disabled in the dropdown. Per D-05. Use:
       var enabledActions = node.actions || [];
       if (catalogModels.length === 0) {
         enabledActions = enabledActions.filter(function (a) { return a !== "setup"; });
       }
       Then pass enabledActions to createActionsDropdown instead of node.actions.

    7. In DOMContentLoaded handler (line 629): Add fetchCatalog() call alongside refreshDetail() and refreshPowerState(). Per D-04 — fetched on page load.
  </action>

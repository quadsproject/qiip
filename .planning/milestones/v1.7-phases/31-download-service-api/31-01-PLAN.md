Create inference_proxy/huggingface/downloader.py with class DownloadService:

Constructor __init__(self, cache_dir: str, token: str | None):
- Store _cache_dir, _token as private attrs
- _statuses: dict[str, DownloadStatusResponse] = {} guarded by _lock = threading.Lock() -- per D-06
- _semaphore: asyncio.Semaphore | None = None (created lazily in async context per Pitfall 1)
- _tasks: set[asyncio.Task[None]] = set() (prevent GC per Pitfall 5)

Method _ensure_semaphore(self) -> asyncio.Semaphore:
- If _semaphore is None, create asyncio.Semaphore(2) per D-09
- Return _semaphore

Method get_status(self, repo_id: str) -> DownloadStatusResponse | None:
- Lock-guarded read from _statuses dict

Method get_all_statuses(self) -> list[DownloadStatusResponse]:
- Lock-guarded list(self._statuses.values())

Method async trigger_download(self, repo_id: str) -> DownloadStatusResponse:
- Per D-10: under lock, check if repo_id already has status DOWNLOADING -- if so return it
- Per D-11: allow re-download if status is COMPLETE or FAILED (overwrite entry)
- Under lock: create DownloadStatusResponse with status=DOWNLOADING, started_at=datetime.now(UTC), set it
- Create asyncio task for _run_download, store in _tasks set, add done callback to discard from set per Pitfall 5
- Return the status

Method async _run_download(self, repo_id: str) -> None:
- Acquire semaphore via _ensure_semaphore() with async with
- Log download start with structlog
- Call await asyncio.to_thread(snapshot_download, repo_id, cache_dir=self._cache_dir, token=self._token) per D-01, D-02, D-04
- On success: set status to COMPLETE with completed_at=datetime.now(UTC)
- Exception handling ordered per Pitfall 2: catch GatedRepoError first, then RepositoryNotFoundError, then RevisionNotFoundError, then Exception
- On failure: set status to FAILED with error message string and completed_at
- Import exceptions from huggingface_hub.errors per RESEARCH.md state-of-the-art

Imports: asyncio, threading, datetime (UTC from datetime), structlog, snapshot_download from huggingface_hub, GatedRepoError/RepositoryNotFoundError/RevisionNotFoundError from huggingface_hub.errors, DownloadState/DownloadStatusResponse from inference_proxy.models.admin

| T-31-01 | Information Disclosure | DownloadService token handling | mitigate | Token stored as str|None from SecretStr.get_secret_value() at construction; never logged (structlog won't render plain str token since it's a private attr) |

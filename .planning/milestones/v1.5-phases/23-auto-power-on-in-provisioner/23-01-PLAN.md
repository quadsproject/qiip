    Four files, four edits:

    1. **state.py** — Add POWERING_ON = "powering_on" to ProvisioningStep enum between PENDING and PREFLIGHT (per D-04, Pitfall 3).

    2. **settings.py** — Add two fields to ProvisioningSettings: boot_wait_timeout: int = 300 and boot_wait_interval: int = 10. Follow the existing plain-int-with-default pattern (per D-05).

    3. **provisioner.py** — Three changes:
       - Add redfish_client: RedfishClient | None = None as the last kwarg in __init__(), store as self._redfish_client. Add imports for RedfishClient and RedfishError.
       - Add private method _power_on_if_needed(self, hostname: str) -> None:
         - If self._redfish_client is None: log at INFO "redfish_not_configured, skipping power check" (per D-01, D-02) and return immediately. Do NOT write POWERING_ON state (Pitfall 4).
         - Otherwise: call self._update_state(hostname, ProvisioningStep.POWERING_ON) per D-04/D-07.
         - Try self._redfish_client.power_action(hostname, "On"). Catch RedfishError, log warning "power_on_failed" with hostname and error string (per D-06). Do not re-raise.
         - Call self._wait_for_ssh(hostname) regardless of power_action outcome.
       - Add private method _wait_for_ssh(self, hostname: str) -> None:
         - Deadline-based retry loop using asyncio.get_running_loop().time() + self._settings.boot_wait_timeout (per D-03, D-05).
         - Each iteration: asyncio.wait_for(asyncio.open_connection(hostname, 22), timeout=10). On success, close the writer and return. On OSError/TimeoutError/asyncio.TimeoutError, sleep self._settings.boot_wait_interval and retry.
         - On deadline expiry: log warning "ssh_wait_timeout" with hostname and timeout value. Do not raise — let preflight fail naturally if SSH is truly unreachable.
       - In provision() method: insert await self._power_on_if_needed(hostname) between the PENDING state write (line 188) and the PREFLIGHT state write (line 189).

    4. **main.py** — Add redfish_client=app.state.redfish_client kwarg to the NodeProvisioner constructor call at line 164-170. app.state.redfish_client is already set (line 224 or 227) before this block runs.
  </action>

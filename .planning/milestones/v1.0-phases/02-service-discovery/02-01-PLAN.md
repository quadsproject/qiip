<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| etcd -> gateway | Data read from etcd is untrusted -- may contain malformed JSON or unexpected field types |
| watch thread -> registry | OS thread writes to shared dict; async handlers read from it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | serializer.py | mitigate | Pydantic validation on all etcd values; malformed JSON returns None with warning log per D-12 |
| T-02-02 | Denial of Service | etcd_client.py | accept | etcd unavailability handled in Plan 02 (lifespan graceful degradation per D-09); this plan only creates the wrapper |
| T-02-03 | Tampering | registry.py | mitigate | threading.Lock protects all dict mutations; copy-on-read for get_all prevents external mutation |
| T-02-SC | Tampering | npm/pip installs | mitigate | etcd3gw verified via Package Legitimacy Audit in RESEARCH.md -- slopcheck [OK], OpenStack-maintained, 8+ years on PyPI |
</threat_model>

    Module-level logger via structlog.get_logger().

    Function run_watcher(etcd_client: EtcdClient, registry: NodeRegistry, stop_event: threading.Event, retry_delay: float = 5.0) -> None:
    - Outer loop: while not stop_event.is_set()
    - Try: call etcd_client.watch_prefix() to get (events_iter, cancel)
    - Inner try/finally: iterate events_iter, call _handle_event for each. In finally: call cancel()
    - Check stop_event.is_set() after each event; break if set
    - On any Exception: log structlog.warning with retry_delay context. Use stop_event.wait(timeout=retry_delay) to sleep interruptibly; if returns True (stop_event set), exit loop
    - When events_iter exhausts without exception (stream ended): also reconnect via the outer loop

    Function _handle_event(event: dict, registry: NodeRegistry, prefix: str) -> None:
    - Extract kv = event["kv"], key = kv["key"]
    - Decode key: key.decode("utf-8") if isinstance(key, bytes) else key
    - Check event type: event.get("type", "PUT") per RESEARCH.md Pitfall 3 (proto3 JSON omits default PUT)
    - If "DELETE": derive node_id = key.removeprefix(prefix), call registry.remove(node_id), log info
    - Else (PUT): extract value = kv.get("value", b""). Handle bytes/str: if str, encode to utf-8. Call node_from_etcd(key, value, prefix). If result is not None, call registry.add(node), log info with node_id and endpoint

    Module docstring referencing D-03, D-10 and explaining reconnection necessity (etcd3gw has no built-in reconnection).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| etcd -> gateway (startup) | Initial get_prefix may return malformed data or fail entirely |
| etcd -> gateway (watch) | Watch events may contain unexpected formats or disconnect |
| watch thread -> registry | OS thread mutates shared state read by async handlers |
| client -> get_registry | FastAPI dependency injection exposes registry to request handlers |

| T-02-05 | Denial of Service | watcher.py | mitigate | Reconnection loop with configurable delay prevents permanent watch loss per D-03 |
| T-02-06 | Tampering | watcher.py event dispatch | mitigate | All event values parsed through serializer with Pydantic validation; malformed events skipped |

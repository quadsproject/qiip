## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> gateway | Untrusted HTTP requests from OpenAI SDK clients (internal network) |
| gateway -> vLLM | Outbound requests to vLLM backends (internal network, trusted) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | proxy/node_selector.py | mitigate | Nodes come only from etcd registry, never from client request parameters. Client cannot specify target URL. |
| T-03-02 | Tampering | proxy/client.py | accept | Request body validated by Pydantic before forwarding. vLLM performs its own input validation. Internal network. |
| T-03-03 | Denial of Service | proxy/client.py | mitigate | httpx connection pool limits (max_connections=100), per-phase timeouts (connect=5s, read=120s, write=10s, pool=10s) via ProxySettings. |
| T-03-04 | Information Disclosure | api/errors.py | mitigate | Error responses use generic messages for connection/timeout errors. HTTPStatusError includes vLLM response text but this is internal network. |
| T-03-SC | Tampering | pyproject.toml installs | mitigate | httpx and httpx-sse passed slopcheck in RESEARCH.md Package Legitimacy Audit. Both approved. |

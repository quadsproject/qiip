<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> gateway | OpenAI SDK clients on internal network send requests to FastAPI endpoints |
| gateway -> vLLM | Gateway forwards requests to vLLM backends discovered via etcd |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | api/routes.py | mitigate | Pydantic models validate all inbound requests before forwarding to vLLM. extra='allow' passes unknown fields but known fields are validated with constraints. |
| T-03-06 | Spoofing | api/routes.py | mitigate | Target URL derived from node.endpoint (etcd registry), never from client request parameters. SSRF impossible. |
| T-03-07 | Denial of Service | api/routes.py | mitigate | Connection pool limits and timeouts configured via ProxySettings. Empty registry returns 503 immediately, no upstream connection attempted. |
| T-03-08 | Information Disclosure | api/routes.py | accept | SSE events forwarded verbatim from trusted vLLM backends on internal network. Error messages sanitized for connection/timeout errors. |
| T-03-09 | Denial of Service | main.py lifespan | mitigate | httpx.AsyncClient created with explicit Limits(max_connections=100) and Timeout preventing unbounded resource consumption. |
</threat_model>

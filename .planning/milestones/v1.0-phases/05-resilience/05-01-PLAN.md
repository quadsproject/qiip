## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gateway -> vLLM node /health | Health probe sends GET to node endpoint; response is untrusted |
| circuit breaker state | Shared mutable state accessed from health checker thread and async route handlers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | circuit_breaker.py | mitigate | All state mutations protected by threading.Lock; no external input affects breaker state directly |
| T-05-02 | Denial of Service | health_checker.py | mitigate | Health probes use short timeout (5s) so a slow node cannot block the checker from probing others; probes run sequentially in a single thread |
| T-05-03 | Information Disclosure | health_checker.py | accept | Health probe responses from vLLM nodes are internal network only (no PII, no external exposure) |
| T-05-04 | Spoofing | health_checker.py | accept | Internal network per project constraints; no auth on health probes in v1 |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed in this plan; all imports are from existing dependencies (httpx, structlog, threading, pydantic) |
</threat_model>

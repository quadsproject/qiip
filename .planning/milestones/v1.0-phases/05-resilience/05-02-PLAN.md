<objective>
Wire resilience primitives into the application: start health checker thread in lifespan, add retry-with-failover to proxy routes, record failures in circuit breakers, add graceful shutdown middleware, and extend NodeSelector with exclude support for retry.

Purpose: After this plan, the gateway handles node failures transparently end-to-end: health checks run in the background, failed requests retry on alternate nodes, circuit breakers trip after repeated failures, and shutdown drains in-flight requests before stopping.

Output: Updated `main.py` (lifespan), `routes.py` (retry + circuit breaker), `node_selector.py` (exclude), new `shutdown.py` middleware, integration tests for shutdown, and updated route tests for retry behavior.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> gateway (during shutdown) | New requests must be rejected with 503; in-flight requests must complete |
| gateway -> vLLM node (retry) | Failed node may return malicious/corrupt data on retry; each attempt uses standard error mapping |
| circuit breaker state | Written by route handlers (async) and read by health checker (thread); protected by threading.Lock |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Denial of Service | routes.py retry | mitigate | Retry count bounded by max_retries (default 3); each retry goes to a different node (exclude_node_ids); failed nodes marked UNHEALTHY so they exit the routing pool |
| T-05-06 | Denial of Service | shutdown.py | mitigate | Drain timeout (graceful_shutdown_timeout=30s) caps maximum wait; after timeout, process stops regardless |
| T-05-07 | Elevation of Privilege | shutdown.py middleware | mitigate | Middleware only checks app.state.shutting_down flag (boolean); no user input influences the decision |
| T-05-08 | Tampering | main.py lifespan | accept | shutting_down flag set only in lifespan shutdown path; no external API can set it. Race between flag set and in-flight check is benign (request either completes or gets 503) |
| T-05-09 | Repudiation | routes.py retry | mitigate | Each retry attempt logged via structlog with node_id, attempt number, and error; provides audit trail |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed; all imports from existing dependencies |
</threat_model>

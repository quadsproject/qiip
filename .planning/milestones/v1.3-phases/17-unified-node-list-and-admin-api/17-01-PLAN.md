   ```python
   @admin_router.post("/nodes/setup", status_code=202)
   async def setup_node(
       body: SetupRequest,
       provisioner: NodeProvisioner = Depends(get_provisioner),
       quads_client: QUADSClient | None = Depends(get_quads_client),
   ) -> SetupResponse:
       hostname = body.hostname

       # D-08: dedup guard
       if hostname in pending_hosts:
           raise HTTPException(status_code=409, detail=f"Setup already in progress for '{hostname}'")

       # D-10/D-11: live QUADS re-validation
       if quads_client is not None:
           try:
               available = await quads_client.get_available()
           except QUADSConnectionError as exc:
               raise HTTPException(status_code=503, detail="QUADS unavailable") from exc
           if hostname not in available:
               raise HTTPException(status_code=400, detail=f"Host '{hostname}' is not available in QUADS")

       pending_hosts.add(hostname)

       async def _provision_and_cleanup() -> None:
           try:
               await provisioner.provision(hostname)
           finally:
               pending_hosts.discard(hostname)

       provisioner.fire_background(_provision_and_cleanup())
       return SetupResponse(task_id=hostname)
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gateway -> QUADS API | Live re-validation call at setup time; response determines whether provisioning proceeds |
| operator -> admin API | Operator triggers setup/teardown via admin endpoints; inputs are hostnames |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Spoofing | QUADS availability response | accept | Internal network only, QUADS is a trusted internal service per project constraints |
| T-17-02 | Tampering | pending_hosts set | accept | Module-level set, single process, no external mutation vector. Worst case: a race between two concurrent setup requests for the same host, both pass the check — second provision will fail at etcd registration (idempotent) |
| T-17-03 | Denial of Service | Live QUADS call blocks setup | mitigate | httpx timeout configured via QUADSSettings.timeout (default 10s). QUADSConnectionError caught and surfaced as 503 |
| T-17-04 | Information Disclosure | GPU hardware info in API | accept | GPU vendor/model is operational metadata, not sensitive. Admin API is internal-only |
| T-17-05 | Elevation of Privilege | Setup without QUADS validation | mitigate | When QUADS is configured, setup MUST pass live availability check. When QUADS is not configured, existing behavior (no check) is preserved — this is the operator's choice |
</threat_model>

<interfaces>
From inference_proxy/models/admin.py (AdminNodeResponse fields consumed by JS):
- node_id: str
- endpoint: str (empty string for available nodes)
- model: str (empty string for available nodes)
- status: str
- active_connections: int (0 for available nodes)
- circuit_breaker_state: str ("closed" for available nodes)
- state: str ("available" | "healthy" | "unhealthy" | "provisioning" | "draining")
- actions: list[str] (e.g. ["setup"], ["teardown"], ["teardown", "retry"], ["cancel"], ["force_teardown"])
- gpu_vendor: str | None
- gpu_model: str | None
- gpu_count: int | None

From inference_proxy/services/unified_nodes.py (_STATE_ACTIONS):
- available -> ["setup"]
- healthy -> ["teardown"]
- unhealthy -> ["teardown", "retry"]
- provisioning -> ["cancel"]
- draining -> ["force_teardown"]

Action-to-endpoint mapping (from admin.py):
- setup: POST /admin/nodes/setup with body {"hostname": node_id}
- teardown: DELETE /admin/nodes/{node_id}
- retry: POST /admin/nodes/setup with body {"hostname": node_id}
- cancel: DELETE /admin/nodes/{node_id}
- force_teardown: DELETE /admin/nodes/{node_id}?force=true

QUADS status response (from Plan 01 endpoint):
- { "status": "connected"|"stale"|"unavailable", "last_sync": ISO string|null, "consecutive_failures": int }

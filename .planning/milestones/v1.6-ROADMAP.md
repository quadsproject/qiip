# Milestone v1.6: LLMFit for Best Fit Models

**Status:** SHIPPED 2026-07-26
**Phases:** 25-29
**Total Plans:** 7

## Overview

Integrate the llmfit CLI to recommend which LLM models best fit a server's hardware before deployment. Includes Pydantic models, SSH-based runner, provisioning installation, admin API endpoint, model selection in setup requests, and dashboard recommendations card.

## Milestone Summary

**Key Decisions:**

- soft_step emits WARN on failure, never exits — llmfit install is non-fatal
- Constructor injection (DIP) for LLMFitRunner testability
- shlex.quote for shell safety when passing model names
- Button-triggered fetch for expensive remote llmfit operations (not auto-load)

**Issues Resolved:**

- SSH command execution needed timeout protection (asyncio.wait_for)
- Domain error hierarchy needed for structured 502 responses

**Issues Deferred:**

- Filtering by use-case (coding/chat/reasoning) — FILT-01, FILT-02, FILT-03
- Cached recommendations per-host — CACHE-01
- Fleet-wide model compatibility matrix — FLEET-01

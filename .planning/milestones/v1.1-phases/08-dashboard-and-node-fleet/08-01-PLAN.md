<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> /dashboard | Untrusted client requests HTML page |
| Browser -> /admin/nodes | JS fetch from dashboard to JSON API (same-origin) |
| CDN -> Browser | External Simple.css loaded from cdn.simplecss.org |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | innerHTML in dashboard.js | mitigate | Use textContent for string fields (node_id, endpoint, model). Badge values come from StrEnum (known set). Internal network only. |
| T-08-02 | Tampering | Simple.css CDN | accept | CSS-only file, no JS execution vector. CDN compromise would only affect styling, not data or behavior. Internal dashboard, low-value target. |
| T-08-03 | Information Disclosure | /dashboard route | accept | Dashboard is read-only, exposes same data as /admin/nodes (already public on internal network). No auth in v1 per project constraints. |
| T-08-04 | Information Disclosure | StaticFiles directory traversal | mitigate | Starlette StaticFiles prevents directory traversal by default. Mount at /static with explicit directory path. |
| T-08-SC | Tampering | pip install jinja2 | mitigate | jinja2 is a Pallets project (17+ years, billions of downloads). Verified in RESEARCH.md Package Legitimacy Audit. Disposition: Approved. |
</threat_model>

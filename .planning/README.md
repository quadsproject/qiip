# Planning Archive

This directory contains historical milestone plans, research, reviews, and verification records. It records what contributors knew and ran at the time; it is not the current installation or operations manual. Use the repository `README.md`, `UPGRADING.md`, `.env.example`, and `auto-vllm/README.md` for current instructions.

## Working-tree sanitization

Personal usernames, developer-home paths, and internal infrastructure names have been replaced with neutral examples in the current working tree. The substitutions preserve the technical meaning of the archived records but are not evidence that the example commands remain current.

This is not historical erasure. Earlier Git objects, existing clones, forks, caches, and pull-request diffs can retain identifiers that appeared before the sanitization commit. Removing those copies would require a separately authorized and coordinated history rewrite and force push, invalidating existing commit identities and disrupting every downstream clone. No history rewrite was performed as part of the documentation campaign.
